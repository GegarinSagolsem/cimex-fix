# Proof-of-Fix

## Evidence checklist

- [ ] **RED output** — `run_tests` on the repro test *before* the fix
- [ ] **Culprit commit** — sha + one-line subject (from MCP bisect)
- [ ] **Fix diff summary** — files changed, lines added/removed
- [ ] **GREEN output** — `run_tests` on the repro test *after* the fix
- [ ] **Full suite** — `npx vitest run` → N/N passed, 0 failed
- [ ] **Critic verdict** — pass / conditional / fail + reason
- [ ] **Blast radius** — from the `root-cause` skill output

## PR body template

Fill every `<placeholder>`. Do **not** mention AI, add co-author lines, or "Generated by" footers.

```markdown
## Summary
<One paragraph: what broke, what the fix does.>

## Root cause
<One-sentence root cause from the root-cause report.>

## Proof

**Before fix — RED:**
```
git checkout <fix-sha>~1 -- src && npx vitest run tests/bugproof/case-<id>.test.ts
```
**After fix — GREEN:**
```
git checkout <fix-sha> -- src && npx vitest run tests/bugproof/case-<id>.test.ts
```
Full suite: `npx vitest run` → <N>/<N> passed.

## Blast radius
<Blast-radius section from root-cause report.>

## Critic verdict
<pass / conditional / fail + reason>

🔗 Cimex Fix proof page: <url>
```

## Steps

1. Confirm all checklist items are complete.
2. Fill the template; replace every placeholder.
3. Open the PR using the filled body.
